# Fonts for report PDFs

Noto Sans, Noto Sans Devanagari (Hindi) and Noto Sans Gujarati, Regular and Bold, from
https://github.com/notofonts. Licensed under the SIL Open Font License 1.1 (free to embed in PDFs).
Text is shaped with HarfBuzz (`uharfbuzz`) so Hindi and Gujarati letters join correctly.
